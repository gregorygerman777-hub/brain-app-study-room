# Study Room

Learn a topic with your brain as tutor: explanations, quizzes and saved notes. Starts on quantum computing.

A brain app for [BRAINF](https://github.com/gregorygerman777-hub/BRAINF). It runs as a tab
(`/study`) inside your brain and talks to it through the console's app bridge.

- Permissions: `llm.invoke`, `memory.write`
- Memory layers: semantic (read), semantic (append)

## Install

In your brain: **Settings > Apps**, paste
`https://github.com/gregorygerman777-hub/brain-app-study-room` and approve.

## Files

- `brain-app.yaml`: the manifest (`brain-app/v1`)
- `dist/index.html`: the whole app, no build step
